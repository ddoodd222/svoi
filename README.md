# Свои

**Свои** — это приложение для видеозвонков только со своими людьми.
Есть веб-версия для браузера и приложение для Android.

Один человек создаёт комнату. Это **хозяин**. Комнату можно создать и с телефона.
Хозяин отправляет ссылку остальным. Каждого гостя хозяин впускает сам.

## Что умеет

- Видео и звук. В комнате до 8 человек.
- Показ экрана. С компьютера в браузере и с телефона в приложении для Android.
- Чат во время звонка.
- Код проверки из девяти цифр. По нему хозяин убеждается, что стучится нужный человек.
- Знакомые входят сами. Кого хозяин уже впускал, тот в следующий раз входит без «Впустить».
  Это можно выключить в списке участников.
- Код входа. Хозяин задаёт его по желанию. Гость с этим кодом входит сразу.
- Код хозяина. Задаётся при создании комнаты, не короче 8 знаков.
  Код нужен, чтобы стать хозяином с другого устройства.
  На экране входа нажмите «Я хозяин этой комнаты» и введите код.
- Закрытый вход. Когда все собрались, хозяин может закрыть вход.
  Тогда новые гости не смогут проситься войти. Звонок при этом идёт дальше.
  Кнопка **«Закрыть вход»** стоит в списке участников.
  После нажатия на ней будет написано **«Открыть вход»**. Нажмите её, чтобы снова пускать гостей.
- Удаление участника из звонка.
- Шумодав (убирает шум из вашего микрофона). Три режима: выключен, обычный и сильный.
  Сильный режим глушит стук клавиатуры, гул вентилятора и шум улицы.
  Шум убирается прямо на вашем устройстве. Звук не уходит на чужие серверы для очистки.
  Режим выбирается на экране входа и в настройках звонка (кнопка с ползунками).
- Анти-эхо. Если вы слушаете собеседников через динамики, их голос попадает в микрофон.
  Обычный режим убирает его. Сильный режим нужен для громкой связи.
  Пока говорят другие, собеседники слышат вас тише.
- Окно поверх других. Видео собеседника остаётся на экране, пока вы в другой программе.
- Проверка связи. Кнопка внизу первого экрана. Показывает, пропускает ли ваш интернет звонок.

## Как пользоваться

**Хозяин**

1. Откройте «Свои»: сайт `https://ddoodd222.github.io/svoi/` или приложение на Android.
   Сайт и приложение заработают только после публикации.
   Чтобы опубликовать, скажите агенту: «опубликуй Свои». Подробности в разделе «Как опубликовать».
   `ddoodd222` в адресе — это ваш аккаунт на GitHub.
   Как поставить приложение, написано в разделе «Как установить на Android».
2. Нажмите **«Создать комнату»**.
3. Напишите своё имя и название встречи. Нажмите **«Создать и войти»**.
4. Отправьте ссылку гостям кнопкой **«Отправить»**. Или покажите QR-код с экрана.
5. Гость попросится войти. Вы услышите короткий сигнал.
6. На экране появятся имя гостя и его код проверки.
7. Гость ещё не в комнате. Позвоните ему по телефону или в мессенджере.
   Попросите прочитать код с его экрана. Цифры совпали с кодом на вашем экране? Нажмите **«Впустить»**.
8. Цифры не совпали? Не впускайте. Нажмите **«Отказать»**.

**Гость**

1. Откройте ссылку от хозяина. Подойдёт любой современный браузер.
   Хотите показать экран с телефона? Откройте ссылку в приложении «Свои» для Android.
   Для этого вставьте её в поле **«Есть ссылка?»** на первом экране приложения.
2. Напишите имя и нажмите **«Попроситься войти»**.
3. Хозяин позвонит вам по телефону или в мессенджере и спросит код. Назовите цифры с экрана.
4. Дождитесь, пока хозяин впустит.

Ссылка работает, пока хозяин не удалит комнату.
Список **«Ваши комнаты»** стоит на первом экране «Своих».
Чтобы продолжить встречу завтра, хозяин нажимает **«Открыть»** в этом списке.
Чтобы удалить комнату, хозяин нажимает значок корзины в этом списке.
Комната попадает в список «Ваши комнаты» только на том устройстве, где её создали.
И только в том же браузере или приложении.

## Как это защищено

Здесь коротко. Подробное описание для специалиста лежит в файле [SECURITY.md](SECURITY.md).

**Звонок**

- Звук, видео, экран и чат идут **напрямую** между устройствами участников.
- «Свои» сами шифруют звонок на устройстве каждого участника. И в браузере, и в приложении для Android.
- Нажимать для этого ничего не нужно.
- Расшифровать звонок могут только его участники.

**Ретранслятор**

- Хозяин может подключить ретранслятор. Это компьютер, который передаёт звонок, как почтальон.
- Звонок идёт через ретранслятор, только если напрямую не вышло.
- После подключения ретранслятора у комнаты появится новая ссылка.
- Ретранслятор работает только у гостей, которые открыли эту новую ссылку.
- Как его подключить, написано в разделе «Если собеседники не соединяются».
- Звонок зашифрован, ретранслятор его не прочитает.

**Просьбы войти**

- Просьбы войти идут через общедоступные серверы. Сервер — это компьютер в интернете.
- Серверы передают просьбу от гостя хозяину. Настраивать их не нужно.
- Просьбы зашифрованы, серверы их не прочитают.

**Ссылка и хозяин**

- Ключ комнаты (секрет для шифрования) записан в самой ссылке. Пересылайте её только своим.
- Одной ссылки мало, чтобы войти. Каждого гостя хозяин впускает сам.
- Впустить гостя, удалить участника и завершить звонок может только хозяин.
  «Свои» проверяют, кто дал команду. Команду не от хозяина «Свои» не выполнят.

Абсолютной защиты не бывает.
Шифрование не поможет, если кто-то получил доступ к вашему телефону.
Оно не поможет, если участник снимает свой экран на камеру.
Впускайте только тех, кого знаете.

## Если собеседники не соединяются

Обычно устройства находят друг друга сами.
Иногда в мобильных сетях прямая связь не получается.
Тогда в окне с видео собеседника появится надпись **«Не удаётся соединиться напрямую»**.

Что сделать:

1. Найдите окно с этой надписью. Попросите собеседника из этого окна подключиться к Wi-Fi.
   Вы сами в мобильной сети? Подключитесь тоже.
   Это помогает чаще всего.
2. Если не помогло, хозяин подключает ретранслятор (по-английски TURN).
   Ретранслятор работает как почтальон: передаёт звонок, но прочитать его не может.
3. Хозяин регистрируется на сайте metered.ca или expressturn.com. Эти сервисы бесплатно дают ретранслятор.
4. Сервис выдаст адрес, логин и пароль ретранслятора.
5. Хозяин нажимает **«Завершить»**. Звонок закончится у всех, комната останется.
   Это нужно: настройки ретранслятора включатся, только когда комнату откроют заново.
6. Откроется экран «Встреча завершена». Хозяин нажимает **«На главную»**. Откроется первый экран «Своих».
7. Там хозяин открывает **«Настройки соединения»** и вписывает адрес, логин и пароль.
8. Хозяин нажимает **«Открыть»** у комнаты, где шёл звонок. Она в списке «Ваши комнаты».
9. Ссылка меняется: в неё добавляются настройки ретранслятора.
   Хозяин отправляет гостям эту новую ссылку кнопкой **«Отправить»**.
   Гости открывают её и снова просятся войти. Хозяин сверяет код и впускает каждого, как в начале.
10. Старая ссылка тоже работает. Но звонок по ней идёт без ретранслятора. Поэтому гостям нужна новая ссылка.

## Как опубликовать

Публикация — это выкладка «Своих» в интернет. Её делает агент по вашей команде.

1. Агент создаёт на GitHub репозиторий `svoi`. Репозиторий — это папка с кодом на сайте GitHub.
2. Агент включает GitHub Pages. Это бесплатное место на GitHub, где лежит сайт.
3. Веб-версия появляется по адресу `https://ddoodd222.github.io/svoi/`.
4. Агент прячет ключ подписи в закрытое хранилище GitHub. Ключ подписи — это файл, который доказывает Android, что обновление от вас.
5. GitHub готовит APK. Это установочный файл для Android.
   Ключ лежит в хранилище запертым. GitHub достаёт его только на время, пока готовит APK.
6. GitHub сам выкладывает готовый APK на страницу `github.com/ddoodd222/svoi/releases`.

Хотите другое имя репозитория? Скажите агенту до публикации.
От имени зависят адрес сайта и адрес страницы с APK.

## Как установить на Android

1. Откройте на телефоне `github.com/ddoodd222/svoi/releases`. Адрес заработает после публикации.
2. Скачайте файл, имя которого начинается на `svoi-` и кончается на `.apk`.
3. Откройте скачанный файл.
4. Android спросит, можно ли браузеру ставить приложения. Разрешите.
5. При первом звонке «Свои» попросят доступ к камере, микрофону и уведомлениям. Разрешите.

**Ключ подписи** нужен для обновлений. Без него новая версия не встанет поверх старой.
Из хранилища GitHub ключ обратно не скачать.
Поэтому запасная копия лежит в папке проекта «Видеосозвоны», внутри скрытой папки `.signing`. В Finder её не видно.
Там файл ключа и пароль к нему. Попросите агента сохранить оба в ваш менеджер паролей.

## Ограничения

- Каждое устройство шлёт видео каждому участнику отдельно.
  С каждым новым человеком растёт нагрузка на интернет и телефон. Поэтому в комнате не больше 8 человек.
- Показ экрана с телефона работает только в приложении для Android. Браузеры на телефонах этого не умеют.
- Хозяин нажал **«Завершить»**? Звонок заканчивается у всех. Комната и ссылка остаются.
- У хозяина пропал интернет? Остальные продолжают говорить. Но новых гостей впустить некому.
- Чат не сохраняется. Кто вошёл позже, прошлых сообщений не увидит.

## Для агента

Владельцу этот раздел читать не нужно.

**Где что лежит**

| Папка | Что внутри |
|---|---|
| `web/` | Веб-версия, отдаётся GitHub Pages как есть. Сборки нет. |
| `web/js/crypto.js` | Криптография: ключи, подписи, шифрование. |
| `web/js/signal.js` | Защищённый служебный канал через публичные MQTT-брокеры. |
| `web/js/room.js` | Комната: допуск гостей и прямые соединения WebRTC. |
| `web/js/app.js` | Экраны. |
| `web/js/config.js` | Адрес веб-версии для ссылок из приложения Android. |
| `android/` | Приложение Android. Сборка кладёт внутрь копию `web/`. |
| `tests/` | Автопроверки. |
| `.github/workflows/` | Публикация сайта и сборка APK. |
| `.signing/` | Ключ подписи APK. В гит не попадает. |
| `DESIGN.md` | Контракт оформления. |

При смене имени репозитория править адрес в `web/js/config.js` и в `android/app/src/main/AndroidManifest.xml`.

**Проверки.** Запускать по порядку.

1. Шифрование и канал на настоящих брокерах, 19 пунктов: `cd tests && npm install && npm run channel`.
2. Поднять сайт: `python3 -m http.server 8787 --directory web`.
3. Звонок втроём в Chrome с поддельной камерой, 45 пунктов: `cd tests && npm run e2e`.
   Внутри: допуск по коду, видео у всех, чат, показ экрана, удаление, закрытый вход,
   возврат после перезагрузки, завершение встречи, знакомые, код входа, передача хозяина по коду.
4. Звук, шумодав и анти-эхо, только macOS, 8 пунктов: `cd tests && npm run audio`.
   Речь синтезирует `say`, файлы звука лежат в `~/.svoi-test` (песочница Chrome не читает папку проекта).

**Секреты репозитория:** `SVOI_KEYSTORE_B64` — `.signing/svoi-release.p12` в base64,
`SVOI_KEYSTORE_PASSWORD` — содержимое `.signing/keystore-password.txt`.
